# Power BI Dashboard — Veyra Telecom

This folder contains the Power BI report developed for the Telecom Customer Churn Analysis project.

## Report Pages

1. **Churn Overview** — Overall customer churn performance, KPIs and customer distribution.
2. **Churn Drivers** — Analysis of service adoption, payment methods and customer segments associated with churn.
3. **Early-Tenure Risk & Hypothesis Testing** — Comparison of high-charge and low-charge early-tenure customers, including a two-proportion Z-test and business recommendations.

## Files

- `Veyra_Telecom_Churn_Analysis.pbix` — Interactive Power BI report.
- `Veyra_Telecom_Churn_Analysis.pdf` — Static report preview.
- Dashboard screenshots — Individual page previews.

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Python
- SQL

The dashboard uses the IBM Telco Customer Churn dataset for customer churn analysis.
